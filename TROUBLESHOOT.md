# AuraTube — Performance & Troubleshooting Guide

Get the smoothest performance and lowest GPU/CPU usage with AuraTube.

## Quick Performance Checklist

1. **Verify Hardware Acceleration:**
   Make sure hardware acceleration is enabled in your browser settings:
   - **Chrome / Edge / Brave:** Settings → System → Enable *Use hardware acceleration when available*.
   - **Firefox:** Settings → General → Performance → Check *Use recommended performance settings*.

2. **Recommended Settings for Low-End / Laptop GPUs:**
   - **Quality → Resolution:** Set to `100%` or `50%`.
   - **Quality → WebGL renderer:** Ensure this is `ON`.
   - **Quality → Save energy on static videos:** Set to `ON`.
   - **Ambient light → Spread:** Adjust between `100` and `250` if your GPU fan kicks up.

3. **Multi-Extension Conflicts:**
   If you experience video stuttering, check if other video enhancer or adblock extensions are conflicting with video player canvases. Try testing AuraTube in an Incognito window with other extensions disabled.
